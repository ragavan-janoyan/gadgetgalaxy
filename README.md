💻 GadgetGalaxyApp – Electronic Gadget Management System

Java Desktop Application | Java Swing | Maven | OOP

📌 Project Overview

GadgetGalaxyApp is a Java-based desktop application developed to manage electronic gadgets, product information, and user accounts efficiently.

The application provides a user-friendly graphical interface that allows users to log in, manage product details, and perform basic management operations.

This project demonstrates Object-Oriented Programming (OOP) concepts, Java Swing GUI development, and file handling in Java.

🚀 Key Features

* 🔐 User Login System
* 👤 User Management
* 📱 Electronic Gadget Management
* ➕ Add New Products
* ✏️ Update Product Information
* 🗑️ Delete Products
* 📋 View Product Details
* 💾 File-Based Data Storage
* 🖥️ User-Friendly Desktop Interface

🛠️ Technologies Used

* Programming Language: Java
* GUI Framework: Java Swing
* Build Tool: Apache Maven
* IDE: Apache NetBeans
* Programming Concepts: Object-Oriented Programming (OOP)
* Data Storage: Text Files
* Version Control: Git & GitHub

⚙️ How to Run

1. Clone or download the repository.
2. Open the project in Apache NetBeans.
3. Make sure Java JDK and Maven are installed.
4. Build the project using Maven.
5. Run the Main.java file.
6. Log in and explore the application features.
